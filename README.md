# 🖩 Java CLI Calculator

## 📌 Project Purpose
This project is a simple command-line calculator built in Java.  
It demonstrates modular programming, error handling, and version control practices.  
The calculator supports basic arithmetic operations and is designed as part of an academic activity.

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/maleesha2525/JavaCalculatorApp.git
   ```
2. Navigate to the project folder:
   ```bash
   cd JavaCalculatorApp
   ```
3. Compile the program:
   ```bash
   javac Calculator.java
   ```
4. Run the calculator:
   ```bash
   java Calculator
   ```

## ✨ Features
- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷) with error handling
- Modular functions for each operation
- CLI loop until user quits (`q`)

## 🧪 Testing
